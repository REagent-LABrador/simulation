DRUGGABILITY DOSSIER — PIPELINE FLOW
Small-molecule tractability station. Given a protein target, it decides whether the target is druggable with a small molecule along two axes that are never averaged: retrieved precedent (what has actually been made) and computed tractability (pocket geometry on structures). It reports evidence; it does not decide whether to pursue.
9 SKILLS · graph-intake → precedent-lookup / terminated-programs · structure-select → pocket-scan · falsification-sweep · assemble-dossier · GPU: cofold-check · ppi-hypothesis

STAGE 00 — RESOLVE THE TARGET
graph-intake · graph_read.py (stdlib) 00GRAPH INTAKE
Reads the upstream literature evidence graph (things, links, findings, papers, gaps) and extracts the input contract from it: which node is a protein target, what the molecule is meant to stop, and which UniProt accession that resolves to (node names / aliases → accession). The one place in the pipeline that talks back upstream.
Four ask verbs, no fifth — expand_node, resolve_link, test_gap, new_question · five conjunctive gates that refuse anything a local table, registry, structure or arithmetic can settle.
Does NOT assess tractability, rank targets, decide an unstated mechanism, or treat a computed result as literature evidence. A pending ask never blocks a verdict and never justifies a null.

AXIS 1 · LOOKED UP
RETRIEVED PRECEDENT
What has actually been made against this target. The stronger axis when it exists. Never computed.
precedent-lookup · modality.py 01PRECEDENT LOOKUP
Measured bioactivities, approved and clinical drugs, family activity — from ChEMBL / PDB / UniProt views, joined on accession via the Paperclip SQL tool. Modality first: every drug and compound is classified small-molecule vs biologic before any precedent claim.
chembl_v / pdb_v / uniprot_v views · compound modality from SMILES via modality.py (RDKit, 2D), not from molecule_type (abstains on 59% of compounds). Splits target / family / structural-neighbour / pocket-neighbour precedent, merged never.
Does NOT compute tractability, score druggability, or merge target activity with family activity. An approved antibody is not evidence a small molecule is possible.
terminated-programs 02TERMINATED PROGRAMS
Why clinical programs stopped — ctgov.studies.why_stopped joined to full-text papers by exact-string grep on drug codes (never semantic search). Contradictory sources reported side by side with their dates.
Does NOT score druggability or decide a target is dead. Rule 7: clinical failure is not evidence against tractability (RORγt — sub-nM leads, zero approvals).
AXIS 2 · COMPUTED
COMPUTED TRACTABILITY
What the structure says about whether a small molecule could bind. Computed, with declared blind spots (cryptic pockets).
structure-select · ligand_filter.py 03STRUCTURE SELECT
Picks the structure(s) to scan, and the chains that constitute the site (from mechanism_hypothesis). Holo vs apo is classified by actual ligand chemistry, not by label. Assembles an ensemble, applies the as-of cutoff, splits domains, and finds structural neighbours with Foldseek.
Selection order: (1) experimental holo → (2) experimental apo (PDB) → (3) homolog-transfer anchor (homolog_transfer.py, three guards) → (4) ESMFold predicted-structure fallback. Never predict what the PDB already holds.
Does NOT score pockets or decide tractability.
pocket-scan · Modal CPU · fpocket / mdpocket 04POCKET SCAN
Pocket geometry over the ensemble. fpocket detects (clustering D swept {1.6, 2.4}); PRANK ranks; mdpocket fixes one site across superposed structures. Plus disorder, cryptic-pocket mechanism, and pocket-vs-interface classification.
modal_app.py wires in cryptic_analysis.py, interface_analysis.py, disorder.py. Volume is absolute (comparable across structures) but carries no verdict; druggability is a within-structure rank only.
Does NOT decide druggability, rank targets, compare a druggability value across structures or to a threshold, or read a low score as evidence against tractability (blind to cryptic sites).
GPU · OFF DEFAULT PATH · STRUCTURE-LESS ONLY · RETURNS WITH WARNINGS, NEVER NULLS
ESMFold FALLBACK & GPU PROTO-TOOLS
The only place the default pipeline touches a GPU. Reached only when no experimental structure and no usable homolog exist — so the computed axis still returns something instead of nulling. Rule 13: in the deployed sandbox the predictor tools are unavailable, so this branch is genuinely off the default path.
  • predicted_structure_fallback.py — folds a structure-less target with ESMFold and hands it to the ordinary pocket scan with warnings, never a null. pTM ≥ 0.80 is a confidence band, not a pass/fail gate; a low pTM lowers fold_confidence, it does not refuse.
  • cofold-check · predict.py — four proto-tools: Boltz-2 cofold (pose), Boltz-2 affinity (binder triage only), ESMFold, BioEmu. repack.py (FASPR) rebuilds side chains so BioEmu backbone frames can reach a pocket finder.
  • ppi-hypothesis — cofolds the target against candidate partners; a surviving, graph-absent interface earns a question back upstream (issued zero asks in 15 measured cases).
↓   the two axes meet — and are reported separately   ↓
falsification-sweep 05FALSIFICATION SWEEP
Attacks the assembled claim before it is reported: do actives collapse to one assay / series / lab; is a holo ligand a known frequent hitter; does the pocket appear in one crystal form only; is it a crystallisation artifact; were programs terminated and why. Records checks that found nothing as well as ones that found something.
Does NOT produce a verdict and adjusts no number — it attaches evidence to falsification{} for the reader to weigh.
↓
THE TWO AXES ARE NEVER AVERAGED — THERE IS NO OVERALL NUMBER
They answer different questions and are allowed to disagree. When they do, the disagreement is named in axis_conflict and left unresolved. The verdict names which axis carried it in verdict_basis — a label over two axes with no basis named is an average with extra steps.
assemble-dossier · validate_dossier.py (stdlib) 06ASSEMBLE DOSSIER
Walks the blocks from every upstream skill into the typed JSON template: both axes kept separate, every number carrying provenance, anything not retrieved null with a line in not_found (never a zero). The only place the verdict is written. Ends on a machine gate — validate_dossier.py must return zero violations (18 named rule codes incl. AXES_AVERAGED, NULL_IS_NOT_ZERO, DRUGGABILITY_LOAD_BEARING, VOLUME_NOT_PRIMARY) before the JSON returns.
VERDICT (a label, not a number)
small_molecule_tractable not_tractable insufficient_evidence
verdict_basis (which axis carried it)
retrieved_precedent computed_tractability both none
insufficient_evidence is a correct answer and stays reachable. Druggability alone may never carry a not_tractable or insufficient_evidence verdict (load_bearing: false). When the axes disagree, axis_conflict is populated and explained — e.g. TNF-α: strong pocket, zero approved small molecules → both, conflict declared.
